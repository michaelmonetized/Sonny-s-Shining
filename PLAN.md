# Sonny's Shining - Development Plan

## Project Overview

Sonny's Shining is a retro-styled side-scrolling beat-em-up video game inspired by classic arcade games and the golden age of cinema. Set in 1935 New Year's Eve, players control Sonny, a pro bowler chasing his girl Lucy through 8 brutal levels across a noir city, fighting bosses inspired by silent film and vaudeville celebrities.

**Key Features:**
- Rubber hose / Fleischer Studios art style
- Bowling-themed combat (towel catch-and-return mechanic)
- Multiple gameplay perspectives (isometric, fighting game, overhead chase)
- Brutal boss finishers
- Cross-platform release (Steam, iOS, Android, macOS)

## Phase 1: Prototype (Months 1-4)

### Goals
- Validate core gameplay loop
- Establish art pipeline
- Build vertical slice of Level 1

### Deliverables
- [ ] Movement and combat system prototype
- [ ] Towel catch-and-return mechanic implementation
- [ ] One complete level (Bertie's Bustling Bubbles)
- [ ] One boss fight (Bertie) with fatality
- [ ] Character art pipeline established (Sonny, Bertie, waitresses)
- [ ] Basic UI (health, score)

### Technical Tasks
- Engine selection and project setup
- Isometric camera system
- Projectile detection and physics
- Animation state machine
- Input handling (keyboard, controller)

## Phase 2: Alpha (Months 5-8)

### Goals
- Complete all 8 main levels
- Implement all boss encounters
- Add bonus chase level
- Polish combat and progression

### Deliverables
- [ ] Levels 2-7 (Charlie through Ivy)
- [ ] Level 8 (Kewpie's Klipper) + final boss
- [ ] Bonus chase level with overhead perspective
- [ ] Fighting game camera for boss fights
- [ ] All 8 boss characters with unique patterns
- [ ] All fatality sequences
- [ ] Power-up system (Ball Launcher)
- [ ] Scoring and combo system

### Technical Tasks
- Camera perspective switching
- Vehicle gameplay for chase level
- Boss AI patterns
- Cutscene system
- Save/checkpoint system

## Phase 3: Beta and Launch (Months 9-12)

- [ ] Achievements/trophies system

- Cloud save integration
